# Itsukipedia 

A fan-made website dedicated to Itsuki Nakano from the manga and anime series *Gotoubun no Hanayome* (*The Quintessential Quintuplets*).

## Features
- Character page for Itsuki with quick facts, appearance, and personality
- Pages for her sisters and Futaro Uesugi, each with its own background
- Character cards on the "Other Characters" page
- Working keyword search with animations
- Gallery page (work in progress, pictures coming soon)

## How to view
Open `index.html` in your browser.

## Built with
HTML, CSS, and JavaScript
