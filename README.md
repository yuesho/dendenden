# Itsukipedia

A fan-made wiki dedicated to Itsuki Nakano from the manga and anime series *Gotoubun no Hanayome* (*The Quintessential Quintuplets*). It's a multi-page website where fans can read about Itsuki, her sisters, and Futaro Uesugi, with each character page styled with its own background and colors.

## Features
- Character page for Itsuki with quick facts, appearance, and personality sections
- Pages for Ichika, Nino, Miku, Yotsuba, and Futaro
- Character cards on the "Other Characters" page that link to each page
- Keyword search that jumps to the right page, with fade and shake animations
- Sticky search bar, neon glowing links, and a floating logo
- Gallery page (work in progress, pictures coming soon)

## How I built it
The site is plain HTML, CSS, and JavaScript with no frameworks. Layouts use CSS flexbox and grid, the animations use CSS keyframes, and the search is a small JavaScript script that matches keywords to pages.

## How to run it
Open `index.html` in any browser, or visit the live demo at https://curious-lebkuchen-242f81.netlify.app/
